# Structura Solver

**Browser-based 2D structural analysis for trusses, beams, and frames.**

Structura is a free structural analysis application based on the **direct stiffness method**. It runs directly in the browser, with no installation, account, or registration required.

### Features

- Structural model visualisation
- Axial force diagrams
- Shear force diagrams
- Bending moment diagrams
- Deformed shape visualisation
- Support reactions
- Nodal displacements
- Member forces
- Step-by-step calculation details
